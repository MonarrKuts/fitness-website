# Crown Fitness

A modern, interactive landing page for a personal trainer and online fitness coach in Nairobi.

## Features

- Responsive dark-mode design with an athletic lime accent
- Interactive plan builder (goal, experience and training days)
- Animated stats, scrolling marquee and scroll-reveal effects
- Client results carousel with autoplay and manual controls
- Monthly / quarterly pricing toggle
- Accessible FAQ accordion
- Booking form with inline validation and a success state
- Mobile navigation, active section links and back-to-top control

## Files

- `index.html` — page structure and content
- `style.css` — theme, layout, interactions and responsive styles
- `script.js` — plan builder, carousel, pricing, accordion, form and navigation logic

No frameworks or build step required. Open `index.html` in a browser, or serve the folder with any static file server.

## Customising

Contact details, WhatsApp numbers, pricing, testimonials and imagery are placeholders — swap them for the coach's real details before publishing. Theme colours and fonts are defined as CSS variables at the top of `style.css`.
